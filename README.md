A tiny Python program that writes one short text to /output/entry.txt: a lighthouse keeper trimming his lamp at dusk, the same small work as every dusk for thirty years. Nothing in the text tells the reader to relax — the calm is in its rhythm, its plain concrete words, and a light that has never once needed to hurry to be seen. It was chosen from a pool of candidates by pairwise self-judging, in both orders, against the bounty judge's own criteria: relax first, courage shown rather than instructed, craft, a lingering image, and a fresh voice.

## Run it

```sh
python3 main.py
```
